## Why this repo exists

I'm Devasish, a CS student and freelance developer. I can build products; now I'm sharpening the other half
of being a software engineer: problem-solving. This repo is my notebook. Every Codeforces problem I solve lands
here with a short note on the **pattern**, the **idea**, and its **time and space cost**.

LeetCode practice happens on my [LeetCode profile](https://leetcode.com/u/TechGenDM/).

## How each solution is written

Every file starts with a short note, so anyone (including future me) can understand it in 10 seconds:

```cpp
// Problem: 4A Watermelon (Codeforces) - https://codeforces.com/problemset/problem/4/A
// Pattern: Math (even/odd check)
// Idea: Weight must be even AND more than 2, so both halves can be even.
// Time: O(1)  Space: O(1)
// Solved: 2026-11-23 (Day 1)
```


## My rules

1. Never a zero day. One problem on a busy day still counts.
2. Stuck 35 minutes? Read the editorial, close it, and write the code myself.
3. Every solution gets a note. If I can't explain it, I haven't solved it.
4. Missed a day? No guilt, no double-up. Just continue.
